## درباره سامانه

سامانه دانا برای پاسخگویی به تمامی نیازهای آموزشی مدارس دوره اول و دوم متوسطه و ابتدایی طراحی شده است. معماری این پلتفرم از تفکیک کامل لایه‌ها، مدیریت نشست با توکن‌های امن Bearer (Sanctum-Compatible)، نرمال‌سازی داده‌ها، و هماهنگی کامل بین تم روشن و تاریک پشتیبانی می‌کند.

## نقش‌های کاربری و اطلاعات ورود

سامانه دارای ۳ سطح دسترسی مجزا با رابط کاربری اختصاصی است:

| نقش کاربری | نام کاربری / کد ملی پیش‌فرض | کلمه عبور پیش‌فرض | دسترسی‌ها و قابلیت‌ها |
| :--- | :--- | :--- | :--- |
| **مدیر سامانه (Admin)** | `admin` یا `3333333333` | `1234` یا `123` | داشبورد پایش عملکرد مدرسه، مدیریت دانش‌آموزان، دبیران، کلاس‌ها، دروس، سال‌های تحصیلی، صدور گروهی کارنامه، نظارت نمرات، اعلانات، لاگ امنیتی |
| **دبیر (Teacher)** | `2222222222` | `1234` یا `123` | میز کار دبیر، ثبت نمرات با ضرایب و انواع مختلف، دفتر حضور و غیاب کلاسی، ثبت و تصحیح تکالیف، درج یادداشت‌های آموزشی و انضباطی |
| **دانش‌آموز / ولی (Student)** | `1111111111` | `1111111111` یا `123` | مشاهده کارنامه‌های ماهانه و دوره‌ای، ریزنمرات تحلیلی، وضعیت حضور و غیاب، مشاهده و ارسال پاسخ تکالیف، توصیه‌های معلمان |

> **نکته:** در نوار بالایی سامانه، گزینه‌ای جهت بررسی و سوئیچ سریع بین نقش‌ها (نقش‌های آزمایشی) نیز تعبیه شده است.

## امکانات و بخش‌های سامانه

### ۱. صفحه عمومی (پرتال اطلاع‌رسانی)
- معرفی مجتمع آموزشی، فضاها و امکانات (آزمایشگاه، کتابخانه، سالن ورزشی و سایت رایانه)
- نمایش اطلاعیه‌ها و بخشنامه‌های عمومی با نشان اولویت
- دسترسی سریع به درگاه ورود هر یک از نقش‌ها

### ۲. پنل مدیریت (Admin Portal)
- **داشبورد تحلیلی:** میانگین معدل مدرسه، نرخ حضور و غیاب، نمودارهای آماری و وضعیت دانش‌آموزان
- **مدیریت دانش‌آموزان:** ثبت، ویرایش، حذف، فعال/غیرفعال‌سازی، بازنشانی رمز عبور، خروجی و ورود گروهی با فایل CSV
- **مدیریت دبیران:** ثبت اطلاعات فردی، کد پرسنلی، تخصص و تخصیص کلاس‌ها و دروس مربوطه
- **مدیریت کلاس‌ها و دروس:** پایه‌بندی، تعیین ظرفیت، انتخاب معلم راهنما، تعریف ضرایب و کدهای درسی
- **موتور صدور کارنامه هوشمند:** صدور کارنامه ماهانه (مهر تا اردیبهشت) و ترمی به همراه محاسبه رتبه در کلاس، معدل وزنی، آمار حضور و انضباط با امکان چاپ A4 رسمی و دریافت تصویر PNG
- **نظارت بر نمرات:** بازبینی و پایش تمامی نمرات ثبت‌شده توسط معلمان
- **تابلو اعلانات:** ایجاد اطلاعیه با تعیین جامعه هدف (همه، دانش‌آموزان، دبیران، کلاس خاص) و اولویت (عادی، بالا، فوری)
- **گزارش رویدادها (Audit Logs):** ثبت دقیق وقایع و تغییرات مهم در سیستم همراه با زمان و هویت کاربر
- **تنظیمات مدرسه:** پیکربندی نام مدرسه، نام مدیر، منطقه، استان، نمره قبولی، شماره تماس و آدرس

### ۳. پنل دبیران (Teacher Portal)
- **میز کار کلاسی:** دسترسی سریع به کلاس‌ها و دروس تحت تدریس
- **ثبت نمرات چندگانه:** مستمر، کلاسی، آزمونک، فعالیت، میان‌ترم و پایانی با ثبت تاریخ و توضیحات
- **دفتر حضور و غیاب:** ثبت وضعیت حضور دانش‌آموزان (حاضر، غایب، با تأخیر، موجه) به صورت روزانه
- **تکالیف آنلاین:** تعریف تکلیف جدید، مهلت ارسال، دریافت پاسخ‌های ارسالی دانش‌آموزان و نمره‌دهی همراه با بازخورد
- **یادداشت‌های آموزشی:** ثبت نکات رفتاری و تحصیلی دانش‌آموزان با امکان محرمانه کردن برای مدیریت

### ۴. پنل دانش‌آموزان (Student Portal)
- **داشبورد تحصیلی:** خلاصه عملکرد، آخرین نمرات، تکالیف در انتظار و پیام‌های جدید
- **ریزنمرات:** نمایش تفکیکی دروس همراه با برچسب کیفی (عالی، خیلی خوب، خوب، نیاز به تلاش)
- **کارنامه‌ها:** مشاهده و چاپ کارنامه‌های رسمی ماهانه، نوبت اول، نوبت دوم و کارنامه سالانه
- **کارتابل تکالیف:** مشاهده شرح تکالیف، ارسال متن و فایل پاسخ، و مشاهده نمره و بازخورد دبیر
- **دفتر حضور و غیاب:** مشاهده سابقه غیبت‌ها و تأخیرها با توضیحات
- **پروفایل کاربری:** مشاهده اطلاعات فردی، کلاس، کد دانش‌آموزی و مشخصات تحصیلی

| لایه / بخش | ابزار و کتابخانه | توضیحات |

## راهنمای راه‌اندازی و اجرا

### ۱. پیش‌نیازها
- **Node.js**: نسخه ۱۸ به بالا
- **npm** یا **yarn** یا **pnpm**

### ۲. نصب و اجرای پروژه

```bash
# ۱. کلون کردن مخزن
git clone <repository-url>
cd <repository-folder>

# ۲. نصب وابستگی‌ها
npm install

# ۳. اجرای محیط توسعه (پورت 3000)
npm run dev
```

پس از اجرای دستور فوق، سامانه روی آدرس `http://localhost:3000` در دسترس خواهد بود.

### ۳. بررسی صحت کد و بیلد نهایی

```bash
# بررسی تایپ‌ها و سلامت کد
npm run lint

# ایجاد بیلد نهایی و بهینه‌شده
npm run build

# اجرای سرور پروداکشن
npm start
```

## ارتباط با بک‌اند و احراز هویت

- **نرمال‌سازی داده‌ها (Data Normalization):** سیستم کلاینت طوری طراحی شده است که پاسخ‌های بازگشتی با فرمت استاندارد یا فرمت Laravel Sanctum (مانند فیلدهای snake_case) را به طور خودکار دریافت، نرمال‌سازی و اعتبارسنجی کند.
- **آدرس پایه API:** در فایل `.env` یا متغیرهای محیطی، مقدار `VITE_API_URL` به صورت پیش‌فرض روی `/api` تنظیم است. در صورت اجرای بک‌اند مجزای لاراول روی پورت `8001`، می‌توانید آن را به `http://127.0.0.1:8001/api` تغییر دهید.
- **احراز هویت توکن‌محور:** با ورود موفق، توکن در `localStorage` ذخیره شده و در هدر تمامی درخواست‌های بعدی ارسال می‌گردد.

## موتور صدور کارنامه و محاسبات آموزشی

موتور کارنامه سامانه به صورت خودکار موارد زیر را با دقت بالا محاسبه و صادر می‌کند:
1. **معدل وزنی:** محاسبه میانگین بر اساس ضریب رسمی دروس مصوب آموزش و پرورش
2. **رتبه در کلاس:** محاسبه رتبه بین دانش‌آموزان فعال کلاس
3. **شاخص‌های آماری:** میانگین نمره کلاس در هر درس، بالاترین و پایین‌ترین نمره ثبت‌شده
4. **شاخص‌های انضباطی و حضور:** محاسبه تعداد روزهای حضور، غیبت و تأخیر به همراه نمره انضباط
5. **ارزیابی توصیفی و وضعیت:** تعیین وضعیت قبولی یا نیاز به تلاش بر اساس حد نصاب نمره قبولی مدرسه (پیش‌فرض ۱۰ از ۲۰)
6. **فرمت چاپ استاندارد:** آماده‌سازی خودکار جهت چاپ روی کاغذ A4 با سربرگ، مهر و امضای مدیریت
